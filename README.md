# 📱 Phone Cover Insert Sheet Generator

Generate precise, ready-to-print custom phone case insert sheets with exact outlines for error-free cutting.

## ✨ Features

- **80+ Phone Models** - Apple, Samsung, Google, OnePlus, Xiaomi, and more
- **Image Upload & Adjustment** - Position and scale your design perfectly
- **Live Preview** - See exactly what prints on A4 paper
- **Flexible Layouts** - Choose 2 or 4 sheets per A4 page
- **High-Quality PDF Export** - Precise cutting guides included
- **Mobile Friendly** - Works on all devices

## 🚀 Quick Start

### Local Installation
```bash
npm install
npm start
```

### Deploy to Vercel
```bash
npm install -g vercel
vercel
```

## 📱 Supported Phones

Apple (iPhone 15, 14, 13, 12, SE, 11), Samsung (Galaxy S24, S23, A54, Z Fold), Google Pixel, OnePlus, Xiaomi, OPPO, Vivo, Motorola, Nothing, Realme, Honor, and more!

## 💻 How to Use

1. Select phone company and model
2. Upload an image
3. Adjust position and scale with sliders
4. Choose 2 or 4 sheets per A4 page
5. Export PDF
6. Print and cut!

## 🛠️ Technologies

- React 18.2
- Tailwind CSS
