# Phone Cover Insert Sheet Generator

Generate precise, ready-to-print custom phone case insert sheets with exact outlines.

## Features
- 80+ phone models
- Image upload & adjustment
- Live A4 preview
- High-quality PDF export
- Mobile friendly

## Quick Start
```bash
npm install
npm start
```

## Deploy to Vercel
```bash
npm install -g vercel
vercel
```

## Technologies
- React 18.2
- jsPDF
- CSS-in-JS styling

Made for custom phone case makers and designers.
